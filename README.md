# orb — релизы для Android

Публичный репозиторий с готовыми сборками приложения **orb**
(`com.safechat.app`). Исходный код приложения приватный; здесь лежат только
бинарники релизов.

Приложение распространяется напрямую в виде APK, вне Google Play.

## Последняя версия

- Страница релизов: <https://github.com/darqus/orb-releases/releases/latest>
- Прямая ссылка на APK:
  <https://github.com/darqus/orb-releases/releases/latest/download/safe-chat.apk>

## Установка

1. Скачайте `safe-chat.apk` из последнего релиза.
2. Разрешите установку из этого источника (Android 8+).
3. Откройте файл и подтвердите установку.

Обновление ставится поверх предыдущей версии и сохраняет локальные данные.
Удалять приложение нужно только если сменился ключ подписи — Android в этом
случае откажет с `INSTALL_FAILED_UPDATE_INCOMPATIBLE`.

## Проверка файла

Каждый релиз подписан одним и тем же release-keystore. Размер и SHA-256 APK
указаны в описании релиза и в манифесте обновлений приложения.

```bash
sha256sum safe-chat.apk
```

Отпечаток сертификата подписи (SHA-256):

```text
9F:D2:99:5D:C4:FB:92:83:B4:B2:E1:C6:37:68:39:98:95:7B:3A:2C:43:54:5B:6A:87:05:C3:6C:F2:32:7A:70
```

```bash
apksigner verify --print-certs safe-chat.apk
```

## Что здесь нет

- исходного кода, правил Firestore и конфигурации окружения;
- APK в git-истории: файлы прикладываются к релизам, поэтому клон остаётся
  крошечным, а каждый релиз можно скачать отдельно.

## Предупреждение

APK не проходил проверку Google Play. Android может показать предупреждение
Play Protect — это нормально для приложений, установленных не из магазина.
Устанавливайте сборки только из этого репозитория.
